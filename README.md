# D4Mods Releases

[![Downloads](https://img.shields.io/github/downloads/LeafGithub/D4Mods-Releases/total?label=downloads)](https://github.com/LeafGithub/D4Mods-Releases/releases)

Public releases for my Degrees of Lewdity mods. Source and development are in a separate private repo; this page is where you download builds.

## Available Mods

### Combat UI Rework

Improves the combat interface with:

- **Split-view layout** - Narrative text and action options side-by-side, no more scrolling
- **Layout presets** - Classic, Columns, or Three columns (sprite and stats get their own column on wide screens). Put the actions panel on either side, set the panel height, and keep the action buttons in view with sticky actions
- **Combat stat HUD** - Compact meters for the opponent's arousal, health, anger and trust and your own arousal, pain and stress, over the empty space beside the sprite or in a panel below it. Meters pulse when they change, show a value, percentage or nothing, and can be turned off individually. Stability and air appear when the game shows them, and X-Change Edition adds the two pleasure meters
- **Passage width** - Set your own maximum width for the passage column (replaces PassageWidthSlider, no addon plugins needed)
- **Compact mode** - Reduced spacing for smaller screens

Works with vanilla DOL, DOL Plus and X-Change Edition from a single build. Settings are in the game's Advanced Settings menu and are stored in your browser, so they carry over between saves.

### Outfit Transfer

Export and import your whole set of saved outfits at once, from the Outfit Editor (wardrobe > "Edit all sets"):

- **Bulk export** - Every outfit, or just the ones you tick, to a `.json` file or the clipboard
- **Import with preview** - Choose a file, drop one onto the editor, or paste JSON. Each outfit is marked New, Renamed or Already have it, with a warning for clothing your game doesn't have
- **Search, bulk delete and compact cards** - Filter by name across all pages, delete the selected outfits with confirm and Undo, and fit far more outfits on screen
- **Hide extras** - Drop the Colours and Hair Style rows for a shorter list

Importing only adds outfits and never changes existing ones. The mod stores nothing in your save, so it's safe to add or remove at any time.

## Installation

1. Download the zip for the mod you want from [Releases](https://github.com/LeafGithub/D4Mods-Releases/releases). Releases are named **UI Rework** and **Outfit Transfer**; pick the newest of each
2. Put it in your ModLoader mods folder (or drag & drop it into the mod manager)
3. Enable the mod in the ModLoader interface
4. Refresh the game

## Compatibility

- Requires [SugarCube 2 ModLoader](https://github.com/Lyoko-Jeremie/sugarcube-2-ModLoader) v2.0.0 or newer
- Degrees of Lewdity, Degrees of Lewdity Plus or X-Change Edition with ModLoader support
- No addon plugins needed
